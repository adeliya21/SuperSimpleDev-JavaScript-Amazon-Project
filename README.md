# SuperSimpleDev-JavaScript-Amazon-Project

A front-end e-commerce project built while learning JavaScript through the SuperSimpleDev course. This project recreates core Amazon shopping functionality using HTML, CSS, and JavaScript.

## Features
- Product Catalog — Browse products in a grid layout.
- Shopping Cart — Add items, update quantities, and remove products.
- Checkout Page — Review cart items and order details.
- Order Summary — View order totals and estimated costs.
- Interactive UI — Dynamic page updates using JavaScript.
- Responsive Design — A familiar Amazon-inspired shopping experience.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Modules
- Local Storage
